Toy Elliptic Curve

Curve: y² ≡ x³ + 7 (mod 17)

Base point: G = (1, 5)

a = 0, b = 7, p = 17

How it works

Each step in the chain adds G to the previous point. To add two points P = (x₁, y₁) and Q = (x₂, y₂), we do three steps.

Step 1 — compute the slope m

Case A: different points (chord)

m = (y₂ − y₁) ÷ (x₂ − x₁)   mod 17

Case B: same point (doubling / tangent)

m = (3·x₁² + a) ÷ (2·y₁)   mod 17        (here a = 0)

Division mod 17 means: multiply by the modular inverse.

Step 2 — compute the new x

x₃ = m² − x₁ − x₂   mod 17

Step 3 — compute the new y

y₃ = m·(x₁ − x₃) − y₁   mod 17

Point at infinity

If P and Q have the same x but opposite y (i.e. y₁ + y₂ ≡ 0 mod 17), the result is the point at infinity, written O. This acts like zero in the arithmetic.

Result

The new point is (x₃, y₃), and it is the sum P + Q.
